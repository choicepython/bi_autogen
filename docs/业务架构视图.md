
# 业务架构视图

## 1. 业务目标

为制造行业提供**高准确率**的 BI 数据分析智能体服务：
- 将自然语言查询转化为数据获取 → 分析 → 可视化 → 报告的完整流水线
- 支持多轮对话上下文，用户可基于前序结果追问
- 生产环境优先**准确率和稳定性**，不追求极致速度

## 2. 用户角色

| 角色 | 描述 | 典型场景 |
|------|------|----------|
| **终端用户** | 业务分析师、生产管理人员 | "查询本月生产产出数据"、"对比上月产量趋势" |
| **系统管理员** | 运维人员 | 监控系统运行、查看 Trace、调整路由规则 |
| **业务专家** | 领域专家 | 维护 ES 中的 API schema 和业务技能定义 |
| **开发者** | 系统开发者 | 新增 Agent/工具、扩展路由中间件 |

## 3. 核心业务流程

```
用户提问
  │
  ▼
1. 智能路由 (3层降级)
   ├── 简单闲聊 → RAGAgent 直接回答
   ├── 明确数据查询 → 单Agent执行 (APIAgent/SQLAgent/PyFuncAgent)
   └── 复杂分析任务 → 全团队 DAG 流水线
  │
  ▼
2. 规划 (PlanAgent)
   ├── 理解用户意图
   ├── 检查已有数据 (多轮对话数据目录)
   ├── 必要时向用户提问 (ask_user)
   └── 输出 DAGPlan (任务节点 + 依赖关系)
  │
  ▼
3. DAG 并行执行 (GraphFlow)
   ├── APIAgent → 调用外部API获取数据 → DataContext
   ├── SQLAgent → 执行SQL查询 → DataContext
   ├── PyFuncAgent → Python代码处理 → DataContext
   ├── DataAnalysisAgent → ML分析(预测/异常检测) → DataContext
   ├── RAGAgent → 知识检索 → DataContext
   ├── VisualizationAgent → 图表生成 → ChartArtifact
   └── ReportAgent → 报告生成 → word/ppt/html/pdf
  │
  ▼
4. 结果整合
   ├── TABLE 事件推送结构化数据
   ├── LLM_CHUNK 流式输出自然语言总结
   └── SESSION_END 最终结果
  │
  ▼
5. 后处理
   ├── 存储多轮对话 TurnSummary
   ├── 后台异步数据摘要
   └── 结果缓存 (可选)
```

## 4. 支持的查询类型

| 查询类型 | 路由路径 | 执行Agent | 示例 |
|----------|----------|-----------|------|
| 闲聊问候 | Layer 1 | RAGAgent | "你好"、"谢谢" |
| 知识问答 | Layer 2/3 | RAGAgent | "什么是CNC编程" |
| API数据查询 | Layer 2/3 | APIAgent | "查询本月生产产出数据" |
| SQL数据查询 | Layer 2/3 | SQLAgent | "统计各车间良率" |
| 数据处理 | Layer 2/3 | PyFuncAgent | "计算环比增长率" |
| 时序预测 | Layer 3 | DataAnalysisAgent | "预测下月产量趋势" |
| 异常检测 | Layer 3 | DataAnalysisAgent | "检测良率异常点" |
| 图表生成 | Layer 3 | VisualizationAgent | "画产量趋势折线图" |
| 报告生成 | Layer 3 | ReportAgent | "生成月度生产报告" |
| 复合任务 | Layer 3 | 全团队 DAG | "分析本月产量并生成报告" |

## 5. 多轮对话场景

```
第1轮: "查询本月生产产出数据"
  → APIAgent 获取数据 → DataContext["APIAgent_1"]
  → 返回 TABLE + 文字摘要

第2轮: "按车间分组统计"  (基于第1轮数据)
  → PyFuncAgent 读取 DataContext["APIAgent_1"]
  → 分组统计 → DataContext["PyFuncAgent_1"]
  → 返回 TABLE + 文字摘要

第3轮: "画个柱状图"  (基于第2轮数据)
  → VisualizationAgent 读取 DataContext["PyFuncAgent_1"]
  → 生成图表 → ChartArtifact
  → 返回图表

第4轮: "生成月度报告"  (汇总前3轮)
  → ReportAgent 读取所有历史结论 + 数据目录
  → 生成 PPT 报告
  → 返回文件下载链接
```

## 6. 关键性能指标

| KPI | 目标 | 说明 |
|-----|------|------|
| 首字延迟 | < 2s | SESSION_START 到第一个 LLM_CHUNK |
| 单Agent完成 | < 30s | APIAgent/SQLAgent 等单Agent路径 |
| DAG完成 | < 180s | 全团队 DAG 流水线 |
| 缓存命中率 | > 60% | 重复查询命中缓存 |
| Token消耗 | < 10k | 单轮对话平均 Token |

## 7. 功能模块

| 模块 | 位置 | 职责 |
|------|------|------|

| 数据共享 | `core/data_context.py` | DataContext DataFrame 存储 |
| 结果缓存 | `core/result_cache.py` | 精确+语义缓存 |
| 可观测性 | `observability/` | Trace + LLM日志 |
| 数据库 | `db/` | PostgreSQL 8表 + 异步写入 |

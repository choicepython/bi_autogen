## 2. 核心数据结构

### 2.1 ChatRequest — 请求模型 (`models/chat_request.py`)

```python
class ChatRequest(BaseModel):
    query: str                    # 用户查询
    user: UserInfo                # 用户信息 (user_id, user_name)
    business: BusinessInfo        # 业务上下文 (source_site)
    session_id: str = ""          # 会话ID（多轮对话）
    chat_id: str = ""             # 轮次ID
    agent_type: str = ""          # 指定Agent类型（跳过路由）
    enable_thinking: bool = True  # 思考模式开关
```

### 2.2 StreamEvent — SSE 事件协议 (`models/stream_event.py`)

15种事件类型，完整生命周期：

```
SESSION_START → PLAN_START → PLAN_COMPLETE → AGENT_START →
  (TOOL_CALL → TOOL_RESULT)* → (LLM_CHUNK | THINK_CHUNK)* →
  (DATA_STORED)* → AGENT_END → ... → SESSION_END
```

特殊事件：`TABLE`（表格数据）、`USER_QUESTION`/`USER_ANSWER`（用户交互）、`ERROR`

```python
class StreamEvent(BaseModel):
    type: StreamEventType
    seq: int = 0                 # 全局递增序号
    timestamp: str = ""
    session_id: str = ""
    task_id: str = ""            # DAG任务节点ID
    agent_name: str = ""
    content: str = ""            # 人类可读摘要
    data: dict[str, Any] = {}    # 结构化数据
```

### 2.3 DAGPlan — 规划模型 (`models/dag_plan.py`)

```python
class TaskNode(BaseModel):
    task_id: str                 # 任务ID (如 "1", "2")
    agent: str                   # Agent类型名
    description: str             # 任务描述
    depends_on: list[str] = []   # 依赖的任务ID列表

class DAGPlan(BaseModel):
    tasks: list[TaskNode]
    reasoning: str = ""          # 规划理由
    is_complete: bool = False    # 是否无需执行（直接回答）

    def validate_dag(self)       # 环检测+依赖完整性
    def has_cycle(self) -> bool
    @classmethod
    def from_task_list(cls, tasks: list) -> "DAGPlan"
```

### 2.4 DataContext — 共享数据存储 (`core/data_context.py`)

```python
class DataContext:
    _data: dict[str, pd.DataFrame]   # key → DataFrame
    _lock: asyncio.Lock              # 并发安全
    _MAX_KEYS: int = 50              # LRU淘汰上限

    async def put(key: str, df: pd.DataFrame) -> None
    def get(key: str) -> pd.DataFrame | None
    def list_keys() -> list[str]
    def all_summaries() -> str       # 所有DataFrame摘要（供后台摘要）
    def generate_key(agent_name, task_id) -> str  # 唯一key生成
```

**Key 命名规则**: `{agent_name}_{task_id}` (如 `APIAgent_1`, `PyFuncAgent_2`)

### 2.6 多轮对话模型 (`models/conversation.py`)

```python
class ConversationContext(BaseModel):
    session_id: str
    turns: list[TurnSummary]           # 历史轮次
    data_catalog: list[DataRef]        # 数据目录（跨轮累积）
    current_query: str

class TurnSummary(BaseModel):
    turn_id: int
    query: str
    routing: RoutingSnapshot           # 路由快照
    agent_conclusions: list[AgentConclusion]  # 各Agent结论
    data_produced: list[DataRef]       # 本轮产出数据
    dag_tasks: list[str]              # DAG任务ID列表

class DataRef(BaseModel):
    key: str                           # DataContext 中的 key
    summary: str                       # 数据摘要
    usable: bool                       # 是否可用
    schema: dict[str, str]             # 列名 → 类型
    source: dict                       # 来源 (api_name/tool_name + params)

class AgentConclusion(BaseModel):
    agent_name: str
    status: TaskStatus                 # SUCCESS / FAILED
    conclusion: str                    # 结论摘要（前500字符）
    failure_reason: str = ""
```

## 3. 数据存储方案

### 3.1 PostgreSQL — 持久化存储

8张表，详细设计见 [数据库设计.md](数据库设计.md)。

| 表 | 用途 | 生命周期 |
|----|------|----------|
| `session` | 会话主表 | 每次请求一条 |
| `routing_decision` | 路由决策 | 每次请求一条 |
| `dag_plan` | DAG规划 | FULL_TEAM时一条 |
| `agent_execution` | Agent执行 | 每个Agent一条 |
| `tool_call` | 工具调用 | 每次工具调用一条 |
| `llm_call` | LLM调用 | 每次 LLM 请求/响应一对 |
| `session_feedback` | 用户反馈 | 用户主动评价 |
| `data_context_snapshot` | 数据快照 | 异步归档 |

### 3.2 DataContext — 内存存储

- `dict[str, pd.DataFrame]` 存储在进程内存
- `asyncio.Lock` 保护并发写入
- LRU 淘汰策略 (max 50 keys)
- **跨 Session 隔离**：每个会话独立 DataContext
- DAG 执行结束后通过 `DataContextCache` 跨轮缓存 DataFrame

### 3.3 ConversationStore — 多轮对话存储

```python
class ConversationStore(Protocol):
    async def get_history(session_id) -> list[TurnSummary]
    async def append_turn(session_id, turn: TurnSummary) -> None
    async def get_data_catalog(session_id) -> list[DataRef]
    async def update_data_catalog(session_id, refs: list[DataRef]) -> None
```

默认实现 `InMemoryConversationStore`（进程内存），可替换为 Redis/DB 实现。

### 3.4 结果缓存

- **精确缓存**: `AsyncTTLCache` (query hash → ResultCacheEntry)
- **语义缓存**: `SemanticCache` (SentenceTransformer 嵌入向量相似度)
- 缓存命中时重放 StreamEvent（替换 session_id 和 seq）
- 多轮对话不复用首轮缓存

## 4. 数据流

```
用户查询 (ChatRequest)
  │
  ├─→ SessionManager.start()
  │     ├── ConversationStore.get_history() → list[TurnSummary]
  │     ├── fetch_es_context() → api_meta, skills
  │     └── result_cache.lookup() → CacheLookupResult
  │
  ├─→ BIRouter.route()
  │     └── RoutingResult
  │
  ├─→ AgentLayer.execute()
  │     ├── PlanAgent → DAGPlan
  │     ├── AgentFactory.create() → Agent
  │     └── Agent.on_messages_stream()
  │           ├── Tool调用
  │           │     ├── api_query → DataFrame → DataContext.put()
  │           │     ├── sql_query → DataFrame → DataContext.put()
  │           │     ├── python_exec → DataFrame → DataContext.put()
  │           │     ├── chart_generate → ChartArtifact → DataContext._charts
  │           │     └── report_generate → 文件路径
  │           ├── LLM输出 → LLM_CHUNK / THINK_CHUNK
  │           └── 最终结果 → AGENT_END
  │
  ├─→ TurnResult (agent_records, plan_record, bg_summary)
  │
  └─→ SessionManager.finish()
        ├── DB写入 (session, routing, plan, agent_execution, tool_call, llm_call)
        ├── ConversationStore.append_turn(TurnSummary)
        ├── DataContextCache.save() → 跨轮缓存 DataFrame
        ├── summarize_background() → 后台异步摘要
        └── result_cache.store() → 缓存存储
```

## 5. 数据隔离

| 维度 | 隔离方式 |
|------|----------|
| **Session 级** | 每个会话独立 SessionContext + DataContext |
| **Task 级** | DAG 中每个任务节点独立 TaskContext（共享 DataContext） |
| **ContextVar** | session_id/chat_id/agent_name 在 finally 块清理 |
| **缓存** | 多轮对话不复用首轮缓存（has_history 时跳过缓存检查） |

## 6. 数据安全

| 安全机制 | 实现位置 | 说明 |
|----------|----------|------|
| SQL 注入防御 | `tools/sql_query.py` | sqlparse 验证 + asyncpg 参数化查询 |
| 代码沙箱 | `tools/python_exec.py` | 31 blocked imports + 15 removed builtins + AST 阻断 |
| SSRF 防御 | `tools/api_query.py` | DNS 解析 + ipaddress.ip_address() 校验 |
| 搜索结果截断 | `tools/search_tools.py` | max_result_length 防止 token 爆炸 |
| 数据库写入 | `db/writer.py` | 异步 Queue + batch INSERT，schema drift 防御 |
| DataContext 淘汰 | `core/data_context.py` | LRU (max 50 keys) 防止内存溢出 |
